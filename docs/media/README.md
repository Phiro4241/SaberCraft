## Adding your own screenshots

1. Take the screenshot in game with **F2** (it lands in `.minecraft/screenshots/`). A clean shot: press **F1** to hide the HUD, no other resource packs, a 16:9 window.
2. Save it as PNG (or JPG for large collages) in `docs/media/screenshots/` with a short, lowercase, hyphenated name that says what it shows, for example `vader-duel-mustafar.png`.
3. Keep files under about 1 MB. 1280×720 or 1920×1080 works well on GitHub.
4. Add a row to the table above (what it shows and how it was made) and reference it in the README, for example in the screenshot table:
   ```markdown
   | ![Vader on Mustafar](docs/media/screenshots/vader-duel-mustafar.png) |
   ```
5. Only use images you made yourself in Minecraft with SaberCraft. No film stills, official artwork, logos or images from other people without their permission.

## Visual style

- Dark space background with blue and red blade light, as in the mod icon and banner.
- Captions in the README are short and in English.
- Prefer screenshots without chat messages and test overlays.
