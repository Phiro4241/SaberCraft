## Hinweis zu Fan-Mod und Geld

SaberCraft benutzt Namen aus Star Wars ohne Lizenz. Eine Spendenmöglichkeit neben einer Fan-Mod kann von Rechteinhabern als kommerzielle Nutzung gesehen werden. Die Texte sind deshalb so formuliert, dass Patreon die Arbeit von Phiro unterstützt und nichts verkauft wird: kein Inhalt hinter einer Bezahlschranke, keine Vorteile im Spiel. Modrinth verlangt ohnehin, dass alles auf der Seite Beworbene frei verfügbar ist.
